# Interior Design Website

## Overview
This is a frontend-only website for an interior design business.  
The project focuses on building a clean, modern, and visually attractive user interface to present interior services, projects, and company information.

This website was developed using only **HTML, CSS, and JavaScript**, without any frontend framework or backend system.

## Features
- Responsive design for desktop and mobile devices
- Modern homepage layout
- Navigation bar with smooth scrolling
- Hero section with a strong visual introduction
- Services section
- Project / portfolio showcase
- About section
- Contact section
- Interactive elements with JavaScript
- Clean and elegant UI style

## Tech Stack
- HTML5
- CSS3
- JavaScript
